Bozya VPN для macOS

Открой «Bozya VPN.command». Система спросит пароль администратора.
Если macOS пишет, что файл от неизвестного разработчика: правый клик по файлу → «Открыть».

Первое включение VLESS, белых списков и AI Ultra скачивает Xray.
WARP включается своим туннелем. AI Ultra меняет только DNS.

Чтобы выйти, в окне браузера нажми «Выход». Повторный запуск снова открывает это окно.
